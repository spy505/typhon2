2. PASSWORD CRACKING USING JOHN THE RIPPER
STEP 1: Open terminal and move to Desktop
cd Desktop
STEP 2: Create a new directory
mkdir lab2
STEP 3: Move into the directory
cd lab2
STEP 4: Generate SHA-256 hash of password
echo -n "students123" | sha256sum
STEP 5: Copy the generated hash
STEP 6: Create hash file
nano hash.txt
(Paste the hash and save using Ctrl+O, Enter, Ctrl+X)
STEP 7: Create wordlist file
nano wordlist.txt
(Add possible passwords and save)
STEP 8: Run John the Ripper
john --format=RAW-SHA256 --wordlist=wordlist.txt hash.txt
STEP 9: If needed, edit hash file
nano hash.txt
(Remove unwanted characters like “-”)
STEP 10: Run the cracking command again
john --format=RAW-SHA256 --wordlist=wordlist.txt hash.txt
STEP 11: Display cracked password
john --show --format=RAW-SHA256 hash.txt
Result: Password is successfully cracked
